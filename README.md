# Daylist

**A little more done, one task at a time.**

Daylist is a lightweight daily to-do list for capturing what you need to do and keeping track of your progress. It runs directly in your browser, with no installation, account, or build step required.

## Features

- Add tasks and mark them complete or incomplete
- Filter the list to see all, active, or completed tasks
- Remove individual tasks or clear all completed tasks
- See remaining tasks and a visual completion summary
- Keep tasks saved in your browser between visits
- Responsive layout with keyboard focus styles and reduced-motion support

## Get started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Add a task and start planning your day.

No dependencies or development server are needed.

## How your data is stored

Tasks are saved in the browser's `localStorage` on the device where you use Daylist. They are not sent to a server. Clearing the browser's site data will remove saved tasks, and tasks do not automatically sync between browsers or devices.

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Browser `localStorage`
